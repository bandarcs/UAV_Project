# كشف الأجسام الجوية وتتبعها من فيديو الطائرة المسيّرة

برنامج مشروع التخرج يحلّل فيديو مسجّلًا على الكمبيوتر. يبدأ من شاشة واحدة. تختار الفيديو، والبرنامج يختار نموذج الكشف وحجم الصورة من الخيارات الموجودة على الجهاز. بعدها يحدد YOLOv8 الأجسام داخل الصورة، ويحاول ByteTrack إعطاء الجسم نفسه رقم تتبّع عبر اللقطات.

## التشغيل

من VS Code اختر **File → Open Folder** وافتح مجلد المشروع. في نافذة **Terminal** داخل المجلد شغّل الأمر التالي.

~~~powershell
.\run.bat
~~~

لتحليل فيديو اختر **3**، ثم الصق مسار الفيديو واضغط Enter. تقدر تضغط Enter على طول لتجربة عيّنة Halmstad إذا كانت موجودة.

| الخيار | وش يسوي؟ |
| --- | --- |
| `3` تحليل فيديو محفوظ | يحلّل كل إطار، ثم يفتح فيديو النتائج ويحفظ جدول الكشف وسبب اختيار الإعدادات. |
| `1` محاكاة البث وانقطاعه | يعيد تشغيل فيديو محفوظ. يحفظ جزء الانقطاع كملف محلي ويعيد قراءته بالترتيب. |
| `2` تقسيم الفيديو | يحفظ الفيديو على شكل مقاطع قصيرة. لتحليل أحد المقاطع، افتحه بالخيار `3`. |

على جهاز جديد أو سيرفر، جهّز بيئة بايثون وانسخ النموذج والفيديو حسب [دليل التشغيل](docs/session_workflow.md).

بعد التشغيل، يطبع البرنامج مسار المجلد. في مجلد `analysis` ستجد:

- `decision.json` يبيّن الموديل والحجم وسبب اختيارهم والفئات التي يدعمها الموديل.
- `annotated.mp4` هو الفيديو مع المربعات وأرقام التتبّع المتاحة.
- `detections.csv` هو جدول الكشف، و`summary.json` هو ملخص التشغيل.

## كيف تقرأ الكود؟

الكود الأساسي والأتمتة في ملف واحد هو [uav_project.py](uav_project.py). تجد شرح خطوات البرنامج بالعربي بجانب الأسطر بعد علامة `#`، مثل `//` في جافا.

- `main` و`execute` يقرآن نوع التجربة ومسار الفيديو.
- `run` يأخذ عيّنات ويفحص الإضاءة والوضوح، ثم يقيس سرعة الإعدادات المتاحة ويختار النموذج وحجم الصورة تلقائيًا.
- بعدها يمر الكود على كل صورة في الفيديو المسجّل. يدوّن ما اكتشفه ويحفظ الصورة بالمربعات. في محاكاة البث، يقدر يخفّف عدد الصور التي يحللها حسب سرعة الجهاز.

| المجلد | محتواه |
| --- | --- |
| [`tools/`](tools/) | تجهيز بيانات التدريب، والتدريب، ومقارنة النماذج. |
| [`experiments/`](experiments/) | الكشف اليدوي وتجربة SAHI. يعملان بشكل مستقل عن القائمة الرئيسية. |
| [`tests/`](tests/) | اختبارات اختيار الإعدادات والتحقق من البيانات. |
| `datasets/Halmstad/` و`datasets/local_clips/` | عيّنات Halmstad والمقاطع المحلية للتجربة. ملفات الفيديو تبقى على الجهاز. |
| `weights/` | ملفات النماذج المتاحة على الجهاز. |

## الاختبارات والبيانات
