# تشغيل جلسات UAV

افتح `run.bat` بالضغط المزدوج. اختر `1` لمحاكاة البث والانقطاع، أو `2` لتقسيم الفيديو إلى مقاطع دورية، أو `3` لتحليل مقطع محفوظ. اضغط Enter عند طلب مسار الفيديو لاستخدام عينة Halmstad الموجودة محليًا، أو الصق مسار فيديو من جهازك.

| الخيار | ماذا يحدث |
| --- | --- |
| 1 | يقرأ المقطع المسجّل كمصدر محاكاة. أثناء فقد الرابط يحفظ الإطارات في `onboard/outage.mp4`. عند رجوع الرابط ينقل المقطع إلى `recovered/outage.mp4` ويحلله بترتيب الفيديو ثم يكمل الإطارات التالية. |
| 2 | يكتب ملفات `clips/clip_001.mp4` وما يليها. مدة كل مقطع 3 ثوانٍ افتراضيًا، ويحفظ الجزء المتبقي في المقطع الأخير. |
| 3 | اختر مقطعًا محفوظًا من أي جلسة. يحدد البرنامج الموديل وحجم التحليل تلقائيًا ويعرض الفيديو الناتج بعد المعالجة. |

ابحث عن المخرجات في `runs/uav_sessions`. يحتوي كل تشغيل على `session.json` فيه أوقات الأحداث بحسب زمن الفيديو، و`print_summary.txt` يمكن فتحه وطباعته. عند التحليل ستجد `analysis/annotated.mp4` و`analysis/detections.csv` وفيه وقت الكشف ورقم التتبع عندما يعيّنه المتتبع. يبقى كل تشغيل في مجلده حتى تنقله أو تحذفه.

المحاكاة تعتمد على زمن المقطع الأصلي. يضبط البرنامج التحليل من إطارات تسبق الانقطاع، ثم يسترجع الفترة المحفوظة قبل استكمال الإطارات التالية حتى يبقى الفيديو الناتج مرتبًا. الفئات المدعومة تتبع الأوزان المحلية التي يختارها البرنامج.

## المقطع ومرجعه

اسم العينة `V_AIRPLANE_001.mp4`. احفظ المقطع داخل `datasets/Halmstad/reference_samples` لاستخدامه من قائمة التشغيل. يحفظ البرنامج المرجع في ملخص الجلسة إذا طابق ملف الطائرة أو الطائر أو الطائرة بدون طيار أو المروحية نسخة الباحثين. ## النقل إلى لابتوب آخر

انسخ مجلد المشروع أو استنسخ المستودع. ثبّت Python 3.14 على ويندوز وأنشئ بيئة `venv` جديدة من داخل مجلد المشروع، ثم ثبّت المكتبات.

```powershell
py -3.14 -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

للتشغيل انسخ الأوزان المحلية مثل `yolov8n.pt` إلى مجلد `weights/`، وضع المقطع في مساره أعلاه، ثم افتح `run.bat`. الأوزان ومقاطع الفيديو ومجلد النتائج موجودة محليًا وتُنقل بشكل منفصل عند استخدام GitHub. يختار التحليل GPU عند توفره ويعمل على CPU أيضًا. ابدأ قراءة الكود من `uav_project.py`.

للتشغيل من PowerShell والتحكم بالوقت في العرض:

```powershell
.\run.bat live --outage 3 7
.\run.bat periodic --clip-seconds 3
.\run.bat analyse 'C:\path\to\clip_001.mp4'
```
